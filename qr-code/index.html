About this tool

A QR code is a square barcode that phones can scan to open a link, show text or save contact details. Enter a URL or any text, click Generate and the QR code appears immediately. You can then download it as a PNG image for print or screen use.

How to use it

  1. Type or paste a URL or text. A full URL should start with https://.
  2. Click Generate QR code.
  3. Test it by scanning with your phone camera.
  4. Click Download QR code (PNG) to save the image.

Good to know

What can a QR code hold? Web links, plain text, phone numbers (tel:), email addresses (mailto:) and more. Longer content creates a denser code that is harder to scan.

Printing tips: keep strong contrast between dark modules and the light background, leave a blank margin around the code and print it at least 2 cm wide. Always test the printed code before sharing it.

Static codes: the code contains your data directly. It does not expire and does not track scans.

Frequently asked questions

Does the QR code expire?

No. It encodes your data directly and works as long as the destination link works.

Can I use it commercially?

Yes. The QR code you create is yours to use.

Why will my code not scan?

Content that is too long, low contrast, a blurry print or a code that is too small are the usual causes. Shorten the text or enlarge the code.

Is my data uploaded?

No. The code is generated locally in your browser.
