HTML Entity Encoder & Decoder

Escape special characters as HTML entities, or decode them back.

About this tool

HTML entities let you show characters that have a special meaning in HTML, such as less-than, greater-than and ampersand signs, as plain text. This tool encodes those characters into entities like &lt; and &amp; and decodes entity-encoded text back to normal characters.

How to use it

  1. Paste your text or code into the input box.
  2. Click Encode to escape special characters, or Decode to convert entities back.
  3. Click Copy to copy the output.

Good to know

Characters that are encoded: ampersand (&amp;), less-than (&lt;), greater-than (&gt;), double quote (&quot;) and single quote (&#39;).

Why it matters: escaping user-provided text before it is placed in a page helps prevent broken markup and cross-site scripting (XSS) problems. Use your framework's built-in escaping for real applications.

Decoding: decoding uses the browser's HTML parser, so named entities such as &copy; and numeric entities are supported. Scripts are never run.

Frequently asked questions

When should I encode HTML?

Whenever you display text that might contain characters like < or & inside an HTML page, for example in code samples or user comments.

Does encoding make input safe?

It helps for text placed in HTML body or attribute content, but safe output depends on context. Use proven libraries and framework features in production.

Will decoding run scripts?

No. The decoder parses text in an inert document and only reads text content.

Is my text uploaded?

No. Everything runs in your browser.
