About this tool

This converter changes the format of an image between WebP, PNG and JPG. Choose a file, pick the target format and download the result. Everything happens in your browser using the canvas, so your picture is never uploaded.

How to use it

  1. Choose an image file.
  2. Select WebP, PNG or JPG in the Convert to menu.
  3. Click Convert image.
  4. Click the download link to save the converted file.

Good to know

Which format to pick: use PNG for graphics, screenshots and anything needing transparency. Use JPG for photos when you need wide compatibility. Use WebP for the web, where it usually gives smaller files than JPG or PNG at similar quality.

Transparency: JPG cannot store transparency, so transparent areas become white when you convert to JPG.

Metadata: converting through the canvas removes EXIF data such as camera model and location, which can be a privacy benefit.

Frequently asked questions

Is my image uploaded?

No. The conversion is done locally in your browser.

Does the image dimension change?

No. The converted image keeps the same width and height as the original.

Why is my converted file larger?

Converting a compressed JPG to PNG, for example, usually makes it larger because PNG is lossless.

Is WebP supported everywhere?

All current major browsers support WebP, though some older software cannot open it. Choose JPG or PNG for maximum compatibility.
