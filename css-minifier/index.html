CSS Minifier

Remove comments and whitespace from CSS and see how much you save.

About this tool

Minifying CSS removes characters that browsers do not need, such as comments, line breaks and extra spaces, so the file downloads faster. Paste your stylesheet, click Minify and the tool shows the compressed CSS and how many bytes you saved.

How to use it

  1. Paste your CSS into the input box.
  2. Click Minify CSS.
  3. Review the savings message and the minified output.
  4. Click Copy and use the result in your project.

Good to know

What is removed: comments, line breaks, repeated spaces, spaces around braces, colons, semicolons and commas, and the final semicolon before a closing brace.

What is not changed: selectors, property names and values are preserved. The tool does not rename classes, merge rules or rewrite colors.

Keep your source: always keep the original readable CSS and use the minified file only for production.

Frequently asked questions

Will minifying break my CSS?

For normal stylesheets no. If you use unusual content such as string values with several spaces, check the result. Keep a backup of your original.

How much smaller will my CSS get?

Typically 10 to 30 percent, depending on how much whitespace and how many comments the file has.

Does this replace a build tool?

It is a quick utility for single files. Large projects usually minify automatically in their build process.

Is my code uploaded?

No. Minification runs locally in your browser.
