Base64 Encoder & Decoder

Encode and decode text, and convert images to Base64 data URLs.

About this tool

Base64 is a way of representing binary data, such as text bytes or an image, using only letters, digits and a few symbols. This tool encodes text to Base64, decodes Base64 back into text and converts an image file into a Base64 data URL you can paste into HTML or CSS. Text is handled as UTF-8, so accented letters and emoji work correctly.

How to use it

  1. To encode text, type or paste it into the box and click Encode text.
  2. To decode, paste Base64 into the box and click Decode to text.
  3. To embed an image, click Encode an image and choose a file. The output is a data URL starting with data:image.
  4. Copy the result from the output box.

Good to know

What Base64 is used for: embedding small images in HTML or CSS, sending binary data in JSON or email, and storing credentials in HTTP Basic authentication headers.

Base64 is not encryption. Anyone can decode it, so never use it to protect secrets.

Size: Base64 output is about one third larger than the original data.

Frequently asked questions

Is Base64 secure?

No. It is an encoding, not encryption. It offers no protection for sensitive data.

Does it support Unicode?

Yes. Text is converted with UTF-8 before encoding and after decoding.

Why does decoding fail?

The input may contain characters outside the Base64 alphabet or have incorrect padding. Remove spaces and any prefix such as data:image/png;base64, before decoding.

Are files uploaded?

No. Encoding and decoding happen locally in your browser.
