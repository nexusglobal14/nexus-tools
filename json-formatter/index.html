JSON Formatter & Validator

Validate and beautify raw JSON instantly, with clear error messages.

About this tool

This JSON formatter checks whether your JSON is valid and rewrites it with clean indentation so it is easy to read. Paste any JSON, such as an API response or a config file, and choose a format. If the text is not valid JSON, the tool shows the parser's error message so you can find the problem. You can also minify JSON to remove all extra whitespace.

How to use it

  1. Paste your JSON into the input box.
  2. Click Format with 2 or 4 spaces, or click Minify for the most compact form.
  3. If there is an error, read the message and fix the text it points to.
  4. Click Copy output to copy the result.

Good to know

What counts as valid JSON? Property names and strings must use double quotes. Single quotes, trailing commas, comments and unquoted keys are not allowed by the JSON standard. Values can be strings, numbers, true, false, null, arrays or objects.

Common errors: a trailing comma after the last item, a missing closing bracket or brace, single quotes instead of double quotes, and unescaped quotation marks inside strings.

Frequently asked questions

Is my JSON sent to a server?

No. Parsing and formatting use your browser's built-in JSON functions, so your data stays on your device.

Why does it say my JSON is invalid?

The most common causes are trailing commas, single quotes and missing brackets. The error message gives the position where parsing failed.

What is the difference between formatting and minifying?

Formatting adds line breaks and indentation for readability. Minifying removes them to make the text as small as possible.

Can it handle large files?

It can handle large text, but very large inputs depend on your device's memory and may be slow.
